## 실행 명령
```
PYTHONDONTWRITEBYTECODE=1 python3 -m pytest -q -p no:cacheprovider tests/test_<모듈>.py
```

검증 전후 파일이 달라지면 실패하므로 테스트 캐시·bytecode·빌드 산출물을 worktree에 남기지 않는다.
테스트 자체가 파일을 생성한다면 임시 디렉터리를 사용하도록 기준 커밋에서 준비한다.
