candidate-tests/ output area. Explain what each detects and run them when the
inputs permit. Never replace protected acceptance tests or weaken assertions
to make an implementation pass. The orchestrator reviews and adopts candidates
before they become trusted acceptance checks.

Stay in the assigned worktree and follow the immutable task contract.
