# 수동 세션 간 메시징

`deepseek-worker`는 기존 Claude Code 세션 간 메시징을 유지한다.
`deepseek-duo -w 2`는 메인 하나와 이름이 다른 워커 둘을 tmux에 연다.
`deepseek-duo -w 0 -P impl,review`처럼 설치된 프로필을 사용할 수도 있다.

가벼운 질문·논의나 이미 관리자가 분리한 작업 공간에서 수동 운영할 때 사용한다.
수동 세션에는 task ID·자동 worktree 격리·외부 성공 판정이 없다.
코드 수정 전 독립 worktree를 준비하고 해당 경로에서 워커를 시작해야 한다.
`deepseek-duo` 자체는 모든 pane을 지정 프로젝트에서 시작하므로 같은 파일의 병렬 편집에 사용하지 않는다.

일반 구현과 독립 리뷰는 `deepseek-task` 관리 모드를 사용한다. 대화형 워커가 떠 있지 않아도 된다.
오케스트레이터는 사용자의 목표에서 필요한 워커를 호출한다. 사용자에게 세션 이름을 외우게 하지 않는다.
