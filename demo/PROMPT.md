랩미팅에서 Claude와 로컬 LLM 워커가 연구 작업을 나눠 수행하는 과정을 보여 주고 싶어.
DEMO_ORCHESTRATOR.md를 읽고 준비된 데모를 끝까지 진행해 줘.

계산 backend는 현재 컴퓨터의 로컬 CPU야. 보통 WSL2에서 실행할 거고 원격 GPU나 SSH는 사용하지 마.
두 태스크의 스켈레톤과 테스트, 기준 커밋은 이미 준비되어 있어.
태스크 A의 행 스케일링과 태스크 B의 분포 충실도 계산을 서로 다른 로컬 LLM 워커에 맡겨 줘.
서버가 허용하면 둘을 병렬로 실행하고, 같은 태스크를 중복 실행하지 마.

직접 함수 본문을 채우거나 테스트를 바꾸지 말고, 기존 worker-task로 위임·상태 확인·외부 검증을 진행해 줘.
두 작업이 성공하면 검증된 구현을 tools/finish.py로 불러와 작은 실험과 결과 보고서까지 만들어 줘.
완성 코드는 각 worktree에 보존하고 자동 merge·commit·push는 하지 마.

보고에는 실제 워커 task/attempt ID, 검증 결과, 수정 파일, 로컬 계산 결과와 report.html 경로를 넣어 줘.
커버리지와 검증 성공 여부를 구분하고, 실제 측정한 숫자만 써 줘.
이것을 QCFD 전체 재현이나 양자 우위의 증거라고 설명하면 안 돼.
워커나 권한 문제로 실패하면 성공으로 꾸미지 말고 실패 이유와 남은 작업을 알려 줘.
