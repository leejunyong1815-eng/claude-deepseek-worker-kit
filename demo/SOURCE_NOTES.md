# 참고 대화와 데모 범위

참고한 로컬 대화의 제목은 **「qcfd 로컬 LLM 서브에이전트 벤치마크」**다.
해당 대화와 연결된 재현 계획·기존 오케스트레이터 역할 문서를 읽기 전용으로 확인했다.
대화 원문·서버 인증·연구 결과 묶음·정답지·원본 실험 코드는 데모에 복사하지 않았다.

이 대화에서 사용자는 QCFD 연구를 Claude + 로컬 LLM 서브에이전트 방식으로 재현하고 완성도를 평가하고자 했으며,
후속 요청에서 최소 실행과 Fable 오케스트레이터, GB10에서 서비스되는 Qwen 워커를 명확히 했다.
이전에 계획된 모델 조합이나 장기 재현 계획을 현재 데모가 완료한 사실로 취급하지 않는다.

데모에는 다음 원칙을 반영했다.

- 오케스트레이터가 목표를 태스크로 나누고 워커를 직접 호출한다.
- 커버리지와 올바르게 수행했는지를 구분한다.
- 테스트·검증 파일을 보호하고 모델 외부에서 완료 여부를 확인한다.
- 수치에는 입력·코드·task/attempt·로그 경로를 붙인다.
- 실패·미측정·과대해석을 구분하고 결과를 보존한다.

랩미팅에서 끝까지 보여 주기 위해 연구 과제는 새로 만든 작은 합성 문제로 바꿨다.
행 크기 불균형이 있는 2D Poisson 이산 행렬의 스케일링, 고전 multinomial 표본의 분포 충실도만 계산한다.
고정된 해로 RHS를 생성하므로 연속 PDE에 대한 정확도 수렴 실험은 아니다.
실린더 경계·VQLS·회로 합성·실기 잡음·양자 하드웨어는 포함하지 않는다.

계산 backend는 이번 요청에 따라 로컬 컴퓨터/WSL CPU다. 워커의 LLM 추론 서버와 혼동하지 않는다.
태스크별 worktree는 원래 대화 이후 이 키트에 추가된 관리 실행 방식이며, 과거 캠페인이 같은 방식으로 실행되었다고 주장하지 않는다.
같은 사용자 권한의 worktree는 보안 샌드박스나 블라인드 평가 환경이 아니다.

offline 리허설은 해답을 제공하는 모의 CLI로 실행 경로만 확인한다. 실제 모델 품질·재현 점수·금전적 절감 효과를 증명하지 않는다.
